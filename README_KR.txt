Flight Companion v0.4 — Multi Aircraft (MSFS 2024)

지원 기체
- Asobo Boeing 737 MAX 8 (기존 체크리스트 유지)
- iniBuilds Airbus A320neo V2 (새로 추가; 실제 절차를 참고한 시뮬레이션용 절차)

Windows: START_CHECKLIST.bat 실행
iPad: GitHub Pages 저장소의 루트에 파일 모두 업로드. Safari에서 기존 웹앱을 완전히 닫고 다시 실행. 필요 시 Safari 웹사이트 데이터/오프라인 캐시 갱신.

기체 선택: 왼쪽 상단 AIRCRAFT 선택 메뉴. 기체별 체크 상태는 따로 저장됩니다.
이전 v0.3 Boeing 737 MAX 체크 상태는 동일 브라우저/도메인의 localStorage를 유지할 경우 보존합니다.
백업 내보내기는 선택한 기체만 포함. 불러오기는 동일 기체 백업만 허용합니다.
수동 체크만 지원하며 SimConnect 동기화는 미구현입니다.
실제 운항용이 아니며 iniBuilds 업데이트/항공사 SOP에 따라 절차는 다를 수 있습니다.
